# Cartoon Network

A synchronized, YouTube-only classic cartoon channel for the Infinity channel family.

- 48 half-hour schedule blocks every day
- American cartoons from 1980–2000; no anime
- Daily lineup changes at 12:00 AM in each viewer's local time
- Refreshing during the same local day keeps the same seeded lineup
- Unavailable YouTube videos are skipped automatically
- Live entry, personal rewind, start-over, daily guide, navigation, web search, sharing, and StarCoin credit UI

GitHub Pages: https://www-infinity4.github.io/Cartoon-Network/
